# Security Policy

## Supported versions

Only the latest commit on `main` receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub: **Security → Report a vulnerability** on this repository
(private vulnerability reporting is enabled).

Include a description, reproduction steps and the impact you expect. You should receive an
acknowledgement within 5 working days. Please allow a reasonable time for a fix before any
public disclosure.

## Scope

This is a reference implementation published for learning and architecture review. It is not
operated as a hosted service, so reports should concern the code in this repository.
